# 0.6.0 — Playback Speed Presets

## Design Overview

**Config file:** `~/.config/voxfree/speed` (same pattern as `~/.config/voxfree/voice`). Stores preset name: `slow`, `default`, or `fast`.

**Preset values** (mapped at runtime via mimic3 `--length-scale`):

| Preset | `--length-scale` | Meaning |
|--------|------------------|---------|
| `default` | `1.0` | mimic3 default speed |
| `slow` | `1.15` | ~15% slower |
| `fast` | `0.85` | ~15% faster |

> Note: `--length-scale` works inversely in mimic3 (higher = slower, lower = faster).

## Files to Create/Modify

### New files

1. **`lib/set-speed.sh`** — resolves preset name to `--length-scale` value. Sourceable from any script. Pure lookup, no side effects.

2. **`voxfree-set-speed.sh`** — sets speed config from CLI. Mirrors `voxfree-set-voice.sh` pattern. Called by `voxfree --speed` and GNOME extension.

### Modified files

3. **`install.sh`** (CLI wrapper, lines 191-220) — add `--speed` case

4. **`ReadLoud/voxfree-readloud.sh`** (line 54) — add `--length-scale` to mimic3 call

5. **`ReadLoud/voxfree-readloud-last.sh`** (line 37) — add `--length-scale` to mimic3 call

6. **`ReadLoud/readloud.sh`** (line 95) — add `--length-scale` to speech-dispatcher config template

7. **`ReadLoud/gnome-shell-extension/extension.js`** — add speed presets menu section

8. **`README.md`** — document `voxfree --speed` command + "What's new in 0.6.0" section

## Key Decoupling Choices

- `lib/set-speed.sh` is **pure** — just resolves preset → number. No file writes, no side effects.
- `voxfree-set-speed.sh` handles the write. Clean separation.
- Read scripts just source `set-speed.sh` and use the resolved value.
- GNOME extension calls `voxfree-set-speed` — same mechanism as `voxfree-set-voice`.
- No changes to STT scripts, doctor, or uninstall (speed only affects TTS).
- `voxfree --voice` command remains unchanged.
- `voxfree-indicator` (Python AppIndicator fallback) remains unchanged.

## CLI Usage

```bash
voxfree --speed              # interactive selector
voxfree --speed slow         # set slow
voxfree --speed default      # set default
voxfree --speed fast         # set fast
voxfree --speed current      # show current speed
```
